# multibrand.tech — архивная копия главной страницы

Код главной страницы сайта **«Мультибренд»** (дистрибьютор IT-оборудования, multibrand.tech) на **16.09.2025**.

Сам домен сейчас не отвечает, поэтому копия собрана из веб-архива. Копия на [web-arhive.ru](https://web-arhive.ru/page?url=https%3A%2F%2Fmultibrand.tech%2F&date=20250916&hidden=0), на которую была ссылка, отдаёт содержимое только скриптом (в исходном HTML страницы-обёртки самого снимка нет), поэтому исходник взят из Wayback Machine — снимок той же даты: `20250916231958`.

## Что это за код

Сайт сделан на **Nuxt 3** и отдаёт SSR-разметку:

* `index.html` — готовая HTML-страница: шапка, меню, баннеры, блоки «Преимущества», «Сервис», «Клиенты», «Регионы», подвал, формы заявки;
* в конце документа — payload `window.__NUXT__` (данные, которые Nuxt использует при гидратации) и конфиг приложения;
* `_nuxt/*.css`, `_nuxt/*.woff` — стили и шрифты TT Norms Pro;
* `images/`, `upload/iblock/…` — часть изображений (логотип, фон сервиса, логотипы клиентов).

## Как открыть

```bash
cd multibrand
python3 -m http.server 8000
# затем http://localhost:8000
```

Или из корня репозитория: `python3 -m http.server 8000` → http://localhost:8000/multibrand/

Смотреть только код — просто откройте `index.html`.

## Ограничения копии

* **Ассеты.** У Wayback Machine жёсткий лимит на массовую выгрузку, поэтому часть файлов (остальные CSS, JS-чанки, большинство картинок) скачать не удалось — ссылки на них оставлены абсолютными, на `web.archive.org/web/20250916231958/https://multibrand.tech/...`. В браузере они подгружаются из архива, но при медленном доступе к archive.org страница может «подтормаживать».
* **Скрипты.** Ядро Nuxt подгружается из архива; часть ленивых чанков в архив не попала (HTTP 404), поэтому гидратация может не подняться. На этот случай в конце `index.html` добавлен маленький скрипт, который подставляет картинки из `data-src` — без него страница осталась бы без изображений.
* **API.** Формы, фильтры и корзина обращаются к API домена, которого больше нет, — работать они не будут. Это статическая копия для просмотра кода и вёрстки.
* **Правка Nuxt-конфига.** В конфиге `window.__NUXT__.config` поле `app.baseURL` заменено с `/` на архивный адрес: страница лежит в подпапке `/multibrand/`, и так догружаемые скрипты и картинки продолжают приходить из архива, а не с корня нашего сайта.

## Про скрипт сборки

`../tools/mirror_multibrand.py` — скрипт, которым собрана эта папка. Он идемпотентный: скачанные файлы повторно не запрашивает, поэтому сборку можно запускать несколько раз — каждый запуск докачивает то, что успел.

```bash
# 1. положить архивный HTML снимка в archive/wayback.html
curl -sSL -o archive/wayback.html \
  "https://web.archive.org/web/20250916231958id_/https://multibrand.tech/"
# 2. собрать/докачать зеркало
python3 tools/mirror_multibrand.py
```

Если запускать скрипт из другой папки, путь `archive/wayback.html` задаётся константой `RAW_HTML`.
