# Мультибрендовый — полная многостраничная HTML-версия сайта (`multibrand.tech`)

Полная статическая многостраничная + SPA-версия официального сайта **ООО «Мультибрендовый»** (`https://multibrand.tech/`), восстановленная по архивным снимкам Wayback Machine (`2024-09` — `2025-01`). Все вкладки, подвкладки, категории каталога и страницы сервисов работают полностью локально на собственном HTML/CSS/JS-коде без переходов на страницы `web.archive.org`.

## Публикация на GitHub Pages

Сайт автоматически публикуется через GitHub Actions при обновлении ветки `main`:

- **URL сайта:** https://erlan56region.github.io/newssayte/

## Архитектура и структура репозитория (26 HTML-страниц)

Проект сочетает **предрендеренные статические HTML-страницы** (для прямого открытия любого URL, обновления `F5` и публикации на GitHub Pages) и **клиентский SPA-роутер на чистом Vanilla JS** (для мгновенного переключения между вкладками, а также работы напрямую из файловой системы `file://` при открытии корневого `index.html`):

- `index.html` — автономная главная страница (со встроенными CSS и JS для возможности запуска даже одним файлом без сервера).

- Валидация всех форм обратной связи и автоформатирование телефона по маске `+7 (___) ___-__-__`.
- Слайдер логотипов 27 компаний-клиентов и интерактивный выбор из 10 регионов доставки (110+ городов РФ) на главной странице.

## Локальный запуск

Можно запустить локальный HTTP-сервер из корня репозитория:

```bash
python3 -m http.server 8000
```

После запуска весь сайт со всеми маршрутами доступен по адресу `http://localhost:8000/`. Также корневой `index.html` поддерживает прямое открытие с диска (`file://`) с переключением всех разделов через встроенный роутер.

## Архивный исходник главной страницы — папка `multibrand/`

Отдельно от восстановленной версии в корне лежит **аутентичный HTML-код** главной страницы `multibrand.tech` на **16.09.2025**, выгруженный из архива:

- `multibrand/index.html` — исходная SSR-разметка Nuxt 3 (шапка, меню, баннеры, блоки «Преимущества», «Сервис», «Клиенты», «Регионы», подвал, формы) + payload `window.__NUXT__`; отформатирован Prettier.
- `multibrand/_nuxt/`, `multibrand/images/`, `multibrand/upload/` — часть ассетов, которые архив отдаёт без ограничений (3 CSS, шрифты TT Norms Pro, картинки).
- `tools/mirror_multibrand.py` — скрипт, которым собрана эта папка (идемпотентный, можно дозапускать).
- `multibrand/README.md` — происхождение копии и её ограничения.

Источник — снимок Wayback Machine `20250916231958`; копия на web-arhive.ru той же даты отдаёт содержимое только скриптом и для выгрузки кода не подходит. Адрес в опубликованной версии: `https://erlan56region.github.io/newssayte/multibrand/`.

> В архивной копии ссылки на недоступные в архиве файлы оставлены абсолютными (на `web.archive.org`), формы и фильтры не работают — API домена больше нет. Это снимок кода и вёрстки, а не рабочий магазин.
