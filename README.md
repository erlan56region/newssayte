# Мультибрендовый — статическая HTML-версия из Web Archive (`multibrand.tech`)

Автономная статическая HTML-страница главной страницы сайта **ООО «Мультибрендовый»** (`https://multibrand.tech/`), восстановленная из снимка Wayback Machine:

- **Снимок архива:** `https://web.archive.org/web/20241117233810/https://multibrand.tech/` (17 ноября 2024 г.)

## Публикация на GitHub Pages

Сайт автоматически публикуется через GitHub Actions при обновлении ветки `main`:

- **URL сайта:** https://erlan56region.github.io/newssayte/

## Структура репозитория

- `index.html` — автономная HTML-страница с полным DOM-деревом Nuxt/Vue-шаблона `multibrand.tech`, встроенными стилями дизайн-системы (`TT Norms Pro`, сетки, адаптив), прямыми ссылками на архивные медиафайлы/шрифты в Wayback Machine и чистым Vanilla JS без внешних зависимостей.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages для корректной отдачи статики.
- `.github/workflows/deploy-pages.yml` — workflow автоматического деплоя на GitHub Pages.

## Что входит в `index.html`

- **Шапка (`mb-header`)** с фиксацией и скрытием при прокрутке, выпадающими попапами **«Вендоры»** (Российские / Зарубежные), **«Каталог»** (12 категорий оборудования), **«Сервис»** (7 услуг), формой обратной связи **«Стать партнером»** с маской телефона `+7 (___) ___-__-__` и адаптивным мобильным меню.
- **Первый экран (`mb-video-banner`)** — «Мультивозможности для успешного развития вашего бизнеса».
- **Блок слогана и преимуществ (`mb-slogan-block`, `mb-benefits-list`)** — ключевые показатели компании (`857+` клиентов, `100+` партнёров, `80+` специалистов, `502+` проектов, `10 лет` опыта).
- **Блок брендов (`mb-main-brands`)** — сетка из 18 оригинальных SVG-логотипов вендоров из архива.
- **Блок сервиса (`mb-service-main`)** — ключевые направления сервиса с переходом ко всем услугам.
- **Блок преимуществ и клиентов (`mb-work-main`)** — карточки («Срочность», «Актуальность», «Гарантии») и интерактивный слайдер из 27 логотипов компаний-клиентов.
- **Интерактивная карта поставок (`mb-map-regions`)** — выбор федерального округа / региона со списком из 110+ городов поставки и картой.
- **Подвал (`mb-footer`)** — навигация, контакты (`info@multibrand.tech`, `+7 (495) 127-75-43`) и юридическая информация.

## Локальный запуск

Достаточно открыть `index.html` в браузере или запустить любой локальный статический сервер:

```bash
python3 -m http.server 8000
```

После запуска страница будет доступна по адресу `http://localhost:8000`.
