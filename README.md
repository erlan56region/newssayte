# Сила — интернет-магазин инструментов и техники (tdsila.ru)

Статическая HTML-версия главной страницы интернет-магазина **«Сила»** (Республика Карелия): каталог инструментов и техники, баннеры, блоки категорий, формы обратной связи и подключённые счётчики аналитики.

Исходником был экспорт кода страницы в один файл (`Html.html`, экспорт macOS TextEdit). Код вытащен из таблицы экспорта, раскодирован, вычищен и отформатирован, а сам репозиторий приведён к обычной структуре статического сайта.

---

## Быстрый старт

```bash
git clone https://github.com/erlan56region/newssayte.git
cd newssayte
```

Дальше — любой из вариантов:

| Способ | Команда |
| --- | --- |
| Просто открыть в браузере | двойной клик по `index.html` |
| Локальный сервер (Python) | `python3 -m http.server 8000` → http://localhost:8000 |
| Локальный сервер (Node.js) | `npx serve .` |
| Локальный сервер (PHP) | `php -S localhost:8000` |

> Скрипты страницы обращаются к API магазина по абсолютным адресам (`https://tdsila.ru/...`), поэтому «живыми» формы и корзина будут только при доступе к рабочему домену — локально проверяется вёрстка и разметка.

## Структура репозитория

```
.
├── index.html                        # главная страница сайта (вся разметка, стили и скрипты страницы)
├── README.md                         # этот файл
├── .nojekyll                         # отключает обработку Jekyll на GitHub Pages
├── .gitignore                        # служебный мусор (ОС, редакторы, node_modules)
└── .github/
    └── workflows/
        └── deploy-pages.yml          # авто-публикация на GitHub Pages
```

### Про `index.html`

* Это одна самодостаточная страница: HTML-разметка, инлайновые `<style>` и `<script>` блоки, JSON-LD разметка (`schema.org`), Open Graph мета-теги.
* Ключевая строка — `<base href="https://tdsila.ru/" />`. Благодаря ей все относительные пути (`assets/stylesheet/stylesheet.css`, `assets/javascript/plait.js`, картинки каталога и т.д.) подтягиваются с рабочего домена магазина. Именно поэтому страница корректно выглядит и локально, и на GitHub Pages, хотя самих CSS/JS-файлов и изображений в репозитории нет.
* Внешние ресурсы, которые подключаются со сторонних домены: `tdsila.ru` (шаблон, картинки), `cdn.plait.ru` (рассрочка), `mc.yandex.ru`, `top-fwz1.mail.ru`, `vk.com` (счётчики).

## Публикация (GitHub Pages)

Сайт уже опубликован: **https://erlan56region.github.io/newssayte/**

GitHub Pages отдаёт содержимое ветки `main` (корень репозитория), поэтому любой пуш в `main` обновляет страницу автоматически. Дополнительно в репозитории есть workflow `.github/workflows/deploy-pages.yml`, который публикует тот же корень через GitHub Actions — его можно запустить вручную: **Actions → Deploy static site to GitHub Pages → Run workflow**. Если понадобится переключить источник публикации: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Что было сделано при подготовке репозитория

1. Из экспорта TextEdit (`Html.html`, таблица с построчно заэкранированным кодом) извлечены все строки исходника — 6 915 строк кода плюс пустые строки, в исходном порядке.
2. Раскодированы HTML-сущности (`&lt;` → `<` и т.п.) и убрана служебная разметка экспорта (`<table>`, `<span class="s1">`, ссылки, которыми TextEdit обернул URL).
3. Исправлены явные дефекты разметки: два лишних символа `"` в атрибутах `onmouseout` у кнопок входа через Яндекс/ВКонтакте и незаэкранированные `&` в ссылках (`&type=outlets` → `&amp;type=outlets`).
4. Код отформатирован (Prettier, `print-width 120`); структура тегов, тексты и поведение скриптов при этом сохранены.
5. Файл переименован в `index.html` и положен в корень, чтобы проект открывался как обычный сайт; добавлены `README.md`, `.gitignore`, `.nojekyll` и workflow деплоя.
